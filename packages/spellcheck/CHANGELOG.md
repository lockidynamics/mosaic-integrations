# Changelog

## 0.2.0

- Replace the earlier diagnostic model with the v2 text-diagnostics operation,
  native settings and dictionary surfaces, and package-owned commands.
- Add bounded global and Library Package Data records for policy and dictionary
  entries, plus English and Spanish locale resources.
- Declare Spell Check-owned completion copy for unresolved, incomplete, and
  execution failures. Requires Mosaic 0.0.2. Earlier prototype data is not
  migrated automatically.

## 0.1.0

- Add deterministic English and Spanish dictionary diagnostics.
